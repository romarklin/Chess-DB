# ♟️ ChessDB - Google Edition

[![Google Cloud Platform](https://img.shields.io/badge/Google_Cloud-4285F4?style=for-the-badge&logo=google-cloud&logoColor=white)](https://cloud.google.com/)
[![Static Badge](https://img.shields.io/badge/Cours-purple?style=for-the-badge&link=https%3A%2F%2Fquentin.lurkin.xyz%2Fcourses%2Fpoo%2Fproject25%2F)](https://quentin.lurkin.xyz/courses/poo/project25/)

**ChessDB** est une infrastructure de base de données conçue pour le suivit, le calcul du score et l'archivage de parties d'échecs, utilisable pas les fédérations d'échecs et plus.

---

## 🚀 Fonctionnalités

- **Sauvegarde persistante des parties**
- **Inscription des joueurs**
- **Gestion des competitions**
- **Calcul automatique du score ELO**
- **Affichage statistiques des joueurs**

---

## 🪠 Adaptabilité

-ChessDB est adaptable à d'autres fédérations facilement tant son code est intuitif et simple.
-Fonctionnel aussi bien sur portable que sur ordinateur (ordinateur recomamandé)
